# Quiz

Projeto que estou construindo aos poucos em lives no TikTok. Nas lives, mostro como ir desenvolvendo a API, explicando as escolhas e a evolução do código. Algumas funcionalidades também podem ser feitas fora das lives.

A API atual usa Node.js, TypeScript, Fastify e Zod, com uma Clean Architecture leve: separação suficiente para organizar o projeto sem criar abstrações antes da hora. A estrutura pode evoluir conforme as necessidades aparecerem.

## Estrutura

- [`api/`](api/) — implementação atual da Quiz API, com instruções para rodar e testar as rotas no [README da API](api/README.md).

## Próximos passos

Pretendo continuar evoluindo o projeto aos poucos nas lives e, quando fizer sentido, em algumas implementações fora delas. Também quero fazer uma versão da API em Go como aprendizado. Mais adiante, talvez o projeto ganhe telas e uma aplicação mobile, aproveitando a oportunidade para aprender React Native ou Flutter.
